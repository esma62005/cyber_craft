# CyberCraft (V1)
## Backend
cd backend && python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
uvicorn app.main:app --reload     # http://127.0.0.1:8000/docs
## Frontend
cd frontend && npm install && npm run dev   # http://localhost:5173
## v2 (Secret Rooms, Story, Boss)
Delete any old `backend/cybercraft*.db` (new tables + session token). The browser never receives answers; rooms, story choices and every boss round are validated by the API using the `X-Session-Token` header.
Flow: finish a mission -> its Secret Room opens -> solve it to unlock story chapters 1-3 -> fight The Malware Core.

## Sound
`cd frontend && npm install` (adds howler). Sounds and ambient music are generated by `python3 tools/make_sounds.py`; replace any .wav in `frontend/public/sounds/` with your own files of the same name.
